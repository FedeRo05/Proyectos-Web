# Web Development Projects 


##  Proyectos Incluidos

Aquí puedes ver la evolución desde páginas estáticas hasta aplicaciones con lógica interactiva:

| Carpeta / Proyecto | Tecnologías | Descripción y Enfoque de Aprendizaje |
| :--- | :--- | :--- |
|  **Memorama interactivo** | HTML5, CSS3, JavaScript  | **Desarrollo de lógica:** Creado para aprender las bases de JavaScript (manejo de eventos, lógica de juego, condicionales) y mejorar el diseño visual con CSS, logrando un juego de memoria dinámico. |
|  **Proyecto-1BaltimoreRavens** | HTML5, CSS3  | **Estructura y estilos básicos:** Una página web muy básica dedicada a los Baltimore Ravens. El enfoque principal fue dominar las etiquetas esenciales de HTML y las propiedades iniciales de CSS para maquetar contenido. |

---

##  Ruta de Aprendizaje

1. **Fase 1 (Baltimore Ravens):** Comprender cómo estructurar texto, imágenes y secciones en la web usando HTML y darles un aspecto limpio con CSS.
2. **Fase 2 (Memorama):** Dar el salto a la programación del lado del cliente con JavaScript para manipular el HTML en tiempo real y responder a los clics del usuario.
